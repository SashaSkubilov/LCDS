## Описание

Учебное Java-приложение с графическим интерфейсом для расчёта коэффициента
лени по количеству запланированных и выполненных за день дел. Программа
показывает рассчитанный процент, уровень прокрастинации и поясняющее
сообщение.

## Возможности

- ввод количества запланированных и выполненных дел;
- проверка корректности введённых значений;
- расчёт коэффициента лени;
- отображение уровня прокрастинации и результата в окне приложения.

## Структура проекта

- `src/` — исходный код Java-приложения;
- `.gitignore` — правила исключения временных и сгенерированных файлов из Git.

## Запуск

Откройте проект в IntelliJ IDEA или другой IDE с поддержкой Java, настройте
JDK и запустите класс `Main` из файла `src/Main.java`.
